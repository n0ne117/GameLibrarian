Steam Integration

Your wishlist must be set to Public in Steam → Edit Profile → Privacy Settings → Game details. Use the numeric profile URL (…/profiles/STEAMID64/…). A free Steam Web API key is required — get one here.

IGDB Integration

Used for game search and cover art. Create a free application at dev.twitch.tv to obtain a Client ID and Client Secret.

Backup & Restore

A backup is a single .zip with everything: your library, cover images, wishlist history and all settings — including your Steam API key and IGDB secret in plain text. Keep it somewhere safe. Restoring replaces everything currently in GameLibrarian.
